代码入口：

- `src/train_lowdim.py`：仅新增低维训练，各数据集独立worker。
- `src/replay_frozen.py`：原/新完整快照的冻结头回放、预训练特征控制和像素标签审计。

- `tools/explain_results.py`：统计表和中文说明。
- `tools/monitor.py`：独立监控、持续进度和自动重绘，不启动训练子进程。
