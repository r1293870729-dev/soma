# 四数据集：切换前后逐步测量图

按原种子、模型、权重和输入角色，在新目录确定性重放既有轨迹，补测970–1030与1970–2030的真实每一步指标。每窗口61个点；不插值、不平滑、不修改历史结果。

四个数据集均覆盖原全部5种潜维数与3个seed，共60条件。图像保留原固定S1、当前阶段、各因子与μ/z，以及同父S1稳定流/原900步冻结头；controlled保留历史当前阶段θ普通准确率。所有既有测点必须复现、原模型摘要必须匹配后，才纳入正式补测图。

这一步需要重新计算丢失的中间模型状态，不是把旧图简单拉伸。计算结束后监控器自动更新全部PNG/SVG并生成图片包。源实验、checkpoint、数据集和Python依赖留在原工作区，本目录不是独立可携带训练包。
