现存图像MSE和旧Ξ已有逐批日志，但探针/新Ψ仅每50步记录，controlled旧记录间隔10/200步。为得到真实逐步值，必须确定性重放原更新序列。在新目录中重放与补测，原代码、原配置、原checkpoint及结果只读。不得用插值、平滑、拟合或复制邻近值冒充逐步测量。

图像每一步重放的模型摘要、输入ID、损失与原逐批日志核对；原已测点的探针和新旧信号也必须一致。沿用原S1固定池、当前阶段各任务、μ/z与本地固定潜噪声。原1000步模型/完整Adam状态用于稳定流对照，原900步冻结头旁路诊断。新参考1000只从1001批起使用。

controlled使用未修改的历史runner：原calibration、初始化、原稀疏probe调度保留，额外probe在副本中、屏蔽并恢复所有RNG执行。逐步记录仅改变日志频率，原日志数值（delta_objective因日志间隔不同除外）、15个原checkpoint、原θprobe和末期权重必须吻合。θ仍是当前阶段训练池80/20普通准确率，split/头初始化seed随step变化，微小波动含读出器拟合与划分变化，不是固定独立S1测试。
