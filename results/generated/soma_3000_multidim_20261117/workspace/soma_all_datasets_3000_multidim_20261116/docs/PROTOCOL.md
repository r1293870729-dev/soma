# 3000步多维度实验

四个数据集均按S1/S2/S3各1000步（第1001、2001步切换）运行，保留已有架构、源图角色与探针任务。不会裁剪4000步曲线冒充新轨迹。

- controlled：2/4/8/16/32维，seed0/1/2。历史circle/torus/local生成器与loss_plus_xi保持不变，rec+0.001KL+0.001旧Xi。原seed0的15个在线θ探针值逐项核验；0/1/3000为额外离线评估。历史探针是当前阶段训练池80/20回测，不属于独立旧任务测试。
- dSprites：8/16/32维；Shapes3D、CIFAR：16/32/64维，seed10/11/12。rec+0.0001KL，图像新旧信号均只读。固定独立探针角色保留，µ/z分别报告；dSprites训练重构项是BCE，另记录像素MSE，其他图像为MSE。
- 每个图像父轨迹在更新1000后另分叉S1稳定对照，沿用同一模型和Adam状态，续跑2000步。主轨迹、稳定分支横轴均截止3000；实际计算5000次更新/父轨迹。
- 固定参考0从第一批开始记录；固定参考1000在更新1000后才可因果使用（第1001步起），不倒填早期数值。旧信号预热期间不可用，不伪装成有效零。
- 三类图像前100步的输入、模型哈希和四项损失均与已有S1前缀逐项相等。正式运行继续逐步核验前1000步，核验参考模型与1000步分叉Adam年龄。
- controlled seed0的2/4维复用已核验完整轨迹；8/16/32维为新增只读观察重放原轨迹。seed1/2是新配对重复。原seed0曲线单独显示，三seed汇总另图标注。
- 新增实际训练预算：图像135000更新；controlled新条件30000正式+30000独立校准更新；seed0三维度观察重放9000正式+9000独立校准。42个父条件全部报告，不按好坏删seed或维数。
- 本轮只重跑、可视化，不沿用4000步协议的AUROC阈值和事件窗口，不调参迎合曲线；保留数值异常与失败。原7月代码和环境仍缺失，controlled为历史协议重建，不能宣称7月逐字节复现。

训练代码、配置和外部源码在configs/frozen.json固定SHA256；分析代码另存分析清单。所有结果写入本目录，历史文件只读。
