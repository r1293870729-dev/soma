# 图线的含义与比较边界

本轮所有主轨迹均为3000步，S1/S2/S3各1000步。稳定对照的后2000步是从同一1000步模型分叉的另一条计算路径，两条曲线的横轴都到3000。

## 三条信号

- 旧Ξ：历史方案B的stage-keyed EMA、收缩白化、未按迹归一化的窗口协方差；读出为最大特征值超过MP边界的绝对超额。controlled取原生64维残差，图像使用固定128维随机投影像素残差。预热未满足的读数不视为有效零。
- 新Ψ ref0：按已确认手册工程参数，以更新0次模型建立固定白化与经验edge；对白化残差的窗口协方差按迹归一化后，求所有超过edge谱模态的相对超额和。controlled使用原生残差；图像使用冻结官方ResNet18 avgpool512维的h(x)−h(x̂)。从第一批测量，真实值可以为零。
- 新Ψ ref1000：公式与ref0一致，固定参考改为更新1000次的模型，且之后不更新参考。在线因果读数从第1001批开始；第1到1000批不使用未来参考倒填。

新旧信号的白化、谱归一化、边界、聚合方式及图像读出器均有差异。图中采用双轴标明单位，峰高不能直接当作信号优劣排名。新信号均不反向传播；controlled的历史旧Ξ仍按原训练目标参与反向传播，图像的旧Ξ与新Ψ均只读。

## 探针和时间

controlled保留截图原历史当前阶段θ八分类探针：每个测点在当前阶段原训练池前2048行上按原规则划分80/20，独立拟合线性头，报告普通准确率。原15个测点逐项核验；0/1/3000为按原规则新增的离线评估。它测的是当前阶段θ可读出性，不能直接解释为固定旧任务的遗忘率，也不能当独立最终测试。

三类图像保留原固定独立probe-train/probe-val/probe-test角色，按验证交叉熵选择线性头正则强度，报告探针测试池的平衡准确率。固定S1测的是同一初始任务支持；S2/S3探针只在相应阶段到达后开放。µ与固定潜噪声z分别绘制，不混为一个读出。该probe-test属于开发诊断角色，不解锁主任务最终test。

图像在到达批次t、模型更新t−1次时测量信号和探针。controlled历史信号使用更新前残差，原在线探针保留更新后评估和原日志步号。两者相差一次更新，图中保留原语义。

均值图显示所有已完成seed与其最小—最大范围，阴影不是置信区间。相同seed的不同维数保持原生代码生成规则，没有声称跨维数共享完全相同的潜噪声或controlled shuffle顺序。所有维数和seed都保留，后验饱和、零信号、失败也保留。

MSE是对实际观测元素的平方误差均值；dSprites训练重构目标仍为原BCE，并另记像素MSE。跨数据集输入空间与损失定义不同，图像总览只帮助查看各自轨迹，不作跨数据集性能排名。
