# 最终信号规范：B / mass（2026-10-24）

## 1. 决定
主信号家族固定为 B，谱读出为 mass：全部严格超边缘相对超额之和。论文符号 Ψ_t；必要时写 Ψ_t^(B)。实现标识：B_mass_fixed_white_empirical_v1。白化与边缘遵循实验手册：固定 white 参考 + 独立经验 edge。Ψ 不进入训练 loss，不反向传播。A/edge、C/gap、谱熵只作比较或消融，不再作为待选主信号。

选择 B 冻结的是信号家族，不会自动批准窗口、alpha、beta、样本量、阈值或停止规则。

## 2. 数学定义摘要
更新前模型在冻结读出 h 中产生残差：
ε_t = h(o_t) − h(ô_t)，η_t = (Σ̂_0 + α tr(Σ̂_0)I/dε)^(-1/2)(ε_t − μ_0)。
white 角色的参考均值与协方差只估计一次并冻结。对最近 W 个白化残差构造去均值协方差 C_t，并迹归一化 C̃_t = dε C_t / tr(C_t)。

edge 角色由 N_edge 个互不重叠的完整 W 样本窗口构成。低能量窗口最大特征值记为零且保留在分母；取 k=ceil((1−β)N_edge) 的第 k 个顺序统计量作为固定正边缘 λ⁽⁰⁾_+，不插值。

Ψ_t^(B) = Σ_{i=1}^{min(dε,W−1)} [ λ_i(C̃_t)/λ⁽⁰⁾_+ − 1 ]_+，当 tr(C_t)>η_floor；否则为0。收满W以前状态为 warming-window、数值为null，不是观测到的0。非正/非有限经验边缘是校准失败，不回退为MP或很小正数。

B是无量纲“超边缘相对谱质量”，不是异常方向数量、概率、p值或原始残差能量。活动模态数另存 active_modes。不能把求和改成均值、top-k、平方超额或删掉减1。

## 3. 需要保留的检验
- B>0 与最大特征值越界是同一个二值事件；只用 B>0 报警不能证明 mass 相对 edge 有增量。
- 只有一个活动模态时 B=A；必须报告活动模态分布、B−A、多模态比例。
- 固定 d 和正 edge 下 B 有配置相关上界；它没有统一[0,1]概率界。
- 窗口内统一非零缩放在不跨低能量分支时保持 B；逐样本不同缩放、改变读出坐标或改变参考不享有同一不变性。
