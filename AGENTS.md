# SOMA local-agent contract

Read docs/DELIVERY_STATUS.md first: this initial GitHub PR is not the full binary/source archive. Use the full local bundle before running historical reproduction. Then read EXPERIMENT_AUDIT, PROTOCOL_CONFLICTS, EXPERIMENT_PLAN, TASK_STATUS, the relevant original manual task, and the detailed task registry/cards in the full bundle.

1. Never alter archive/uploads, legacy or results/imported. New runs have unique IDs under results/generated; new analysis goes to reports/local. Preserve failures and unfavorable outcomes.
2. Old entropy Xi, legacy MP/EMA Psi and manual fixed-white empirical-edge Psi are different versions. No curve relabeling. Engineering tests do not certify scientific claims.
3. Never invent AUTHOR INPUT, sample sizes, thresholds, stopping rules, final test unlocks, GPU tests, licenses, DOI or independent acceptance. Unresolved tasks remain blocked.
4. No true stage labels, future sample pools, probe/test labels or final curves may choose an online signal/trigger/candidate/accepted edit. Candidate samples must be role-disjoint AND already arrived.
5. Use pre-update predictions, frozen readout/reference and separate white/edge/edgecov/cal/cover/train/hval/probe-train/val/test. Comparator direction/search/selection may not use the supplied already-viewed tests.
6. Controlled independent units are generator implementations with seeds/events/windows nested. Natural units are independent training runs. Dimensions, windows and training seeds do not automatically add independent n.
7. Q2 conditions share all but the second structural gate. Include Psi/fixed/magnitude/rate-matched-random/oracle; no primary test accepted-count matching.
8. Candidate/null/pre share the parent and approved common random prefix. Explicitly map optimizer slots/age, moments and semantic axes. Record three objectives and all failed resources. Rejection must preserve parent RNG/cursors.
9. RRB is capped recovery duration with no-drop=0, not excess-MSE area. TAEF uses max-cardinality then min-total-delay one-to-one matching. No natural TAEF. Shadow is not randomized causality; P>0.05 is not equivalence.
10. No fabricated final plot points. Preserve raw/display values, IDs, hashes, planned/complete/failed/incomplete/censored/NA and resource ledgers. An independent reviewer, not the executor, marks accepted.
11. Do not load untrusted pickle. Prefer torch.load(weights_only=True) and np.load(allow_pickle=False) for compatible assets. Audit old loaders before execution.
12. No force push, remote-history deletion, automatic public release or invented license. Check expected remote HEAD before writes; use Git LFS for large assets.

Workflow: one task branch/worktree, smallest failure fixture first, fix and replay, then request formal compute only after author freeze and required Gate. Gate A before large Q2, Gate B before final Q3. Metadata preflight is not a security sandbox or scientific review.

Handoff: task ID, exact files, commands, environment/code/config/parent hashes, planned/completed/failed/incomplete units, resource use, tests, deviations, unresolved decisions, supported and unsupported conclusions. Never promote 'code runs' to 'paper experiment complete'.
